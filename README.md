# Kernelnote

Repositório para kernels experimentais destinados ao notebook HP 240 G4 com Intel Core i3-5005U, usando Linux Mint Debian Edition.

## Projeto atual

- Base: Linux 7.1.3 stable
- Patchset: Liquorix v7.1.3-lqx1
- Gerenciamento de memória: Marie LRU 0.7.7
- Distribuição alvo: LMDE 7 / Debian 13 Trixie
- Arquitetura: amd64

O desenvolvimento ocorre em branches experimentais. A branch `main` contém apenas documentação e infraestrutura de validação.
